# Loker MT · MT Hunter

Daftar publik program Management Trainee yang masih buka, dikurasi MT Hunter.

- `index.html`: halaman publik (GitHub Pages).
- `data.json`: data lowongan. Diperbarui setiap hari lewat pull request dari tugas terjadwal Claude.
- `PANDUAN-UPDATE.md`: aturan kurasi dan format data.
- `scripts/validate.py`: pemeriksa format `data.json`.

Untuk menayangkan update harian: buka tab **Pull requests**, baca ringkasannya, lalu klik **Merge pull request**.
